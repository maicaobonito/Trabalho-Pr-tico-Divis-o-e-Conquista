# Casos de teste — Etapa 2: Par de Pontos Mais Próximos
#
# Formato de cada caso:
#   ## <nome>
#   motivo: <o que o caso exercita e por que ele importa>
#   entrada:
#   <n seguido de n linhas "x y">
#   saida:
#   <saída esperada de `python3 etapa2.py`: "distancia i j", i < j, base 1,
#    distância com 6 casas decimais>
#
# Linhas iniciadas por um único "#" são comentários.
#
# Regra de desempate usada nas duas implementações: entre os pares com a
# mesma distância mínima vence o de menor (i, j) em ordem lexicográfica.
#
# Todos os casos são verificados com a força bruta, com a divisão e
# conquista em vários limiares (2, 3, 4 e o padrão) e com o programa de
# linha de comando (ver testes/test_etapa2.py).

# ---------------------------------------------------------------------------
# Tamanhos mínimos
# ---------------------------------------------------------------------------

## dois_pontos
motivo: menor entrada válida; só existe um par (triângulo 3-4-5)
entrada:

0 0
3 4
saida:

motivo: n = 3 é o menor caso em que a recursão com limiar 2 divide (1 ponto de um lado, 2 do outro)
